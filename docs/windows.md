# Установка на Windows 10/11

## Нужно один раз

1. Установи [Python 3.11 или новее](https://www.python.org/downloads/windows/).
   В установщике оставь **Python Launcher (`py`)**. Если `py` не найден,
   измени установку Python и добавь launcher.
2. Установи бесплатный [SumatraPDF](https://www.sumatrapdfreader.org/download-free-pdf-viewer).
   Обычного установщика достаточно. Adobe Reader или Edge можно оставить
   приложением по умолчанию: газета обращается к SumatraPDF отдельно.
3. Скачай репозиторий через **Code → Download ZIP**, распакуй в постоянную
   папку, например `Документы\perovskoye-shosse-times`. Не запускай из ZIP.
4. Двойным щелчком запусти **install-windows.cmd**. Он создаст окружение,
   установит библиотеки и откроет пример. Ничего не печатается.
5. Запусти **configure-windows.cmd**: задай название и источники.
   Если при подключении почты/Telegram Windows показывает пароль пустым —
   это нормально, ввод скрыт. Нажми Enter после ввода.

## Принтер

Добавь принтер в **Параметры → Bluetooth и устройства → Принтеры и сканеры**
(на Windows 10 — «Устройства»). Сначала проверь обычную тестовую страницу.
В меню программы выбери **4**, затем принтер из списка.

SumatraPDF находится автоматически в `%LOCALAPPDATA%\SumatraPDF`,
`%PROGRAMFILES%\SumatraPDF` или PATH. Для portable-версии укажи в `config.json`:

```json
"windows": {
  "sumatra_path": "C:\\Tools\\SumatraPDF\\SumatraPDF.exe"
}
```

Программа отправляет один А4 в выбранный принтер через
[официальный интерфейс печати SumatraPDF](https://www.sumatrapdfreader.org/docs/Command-line-arguments).
Используются односторонняя печать и одна копия. PDF формируется внутри программы;
пароли и данные аккаунтов не передаются SumatraPDF.

## Утреннее расписание

После выбора принтера создаются **задачи текущего пользователя**, без ввода пароля
Windows и без изменения политики выполнения PowerShell:

- `PerovskoyeTimes-Print` проверяет готовый выпуск раз в минуту.
- `PerovskoyeTimes-Awake` удерживает компьютер от автоматического сна на питании.

Их можно увидеть в стандартном **Планировщике заданий**. Время печати берётся
из `config.json`, по умолчанию **08:00 Europe/Moscow**, независимо от часового
пояса Windows. При опоздании утренняя печать не догоняется днём.

Затем настрой **подготовку редактором** в локальном Codex по шагам 4–5
из [README](../README.md). Она запускается отдельно в 07:35.
В её инструкции Python — `.venv\Scripts\python.exe -X utf8`.

Компьютер должен быть включён, пользователь вошёл в свою учётную запись,
настольное приложение работает, крышка ноутбука открыта. Автоматическая
разблокировка Windows не настраивается. Экран может погаснуть.
Подключи питание, принтер и бумагу. Не перемещай папку после установки задач.

## Проверить и отключить

**status-windows.cmd** показывает подключения, текущую дату и состояние печати.
Из PowerShell в папке проекта:

```powershell
.\.venv\Scripts\python.exe -X utf8 gazette.py status
.\.venv\Scripts\python.exe -X utf8 gazette.py demo
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -p 'tests*.py'
```

После просмотра **настоящего** PDF можно напечатать его сейчас:

```powershell
.\.venv\Scripts\python.exe -X utf8 gazette.py print-now
```

Повтор в этот же день заблокирован. При ошибке проверь системную очередь:
нулевой код SumatraPDF означает передачу на печать, но не доказывает выход бумаги.
Если номер задания получить не удалось, позднее зависшее задание придётся удалить
в очереди вручную. Программа не отменяет чужие документы.

Для отключения открой **configure-windows.cmd** → пункт **7**. Это удалит обе
задачи программы. Затем отдельно отключи подготовку в расписаниях приложения.

## Ограничения первой версии

Windows-ветка реализована и покрыта отдельными проверками аргументов печати,
защиты очереди и настройки заданий; CI запускает тесты и создание демо на Windows.
Физический принтер на Windows у автора пока не проверен. Первый проверенный
бумажный выпуск вышел на macOS с HP LaserJet P1102w.
Твой принтер должен иметь работающий драйвер Windows.

Georgia и Arial обычно установлены в Windows. Если ошибка говорит, что шрифт
не найден, восстанови штатные шрифты системы. Linux пока не поддерживается.
